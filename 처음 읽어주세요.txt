모아 투자관리 — Windows에서 처음 실행하기

1. 내려받은 ZIP을 마우스 오른쪽 버튼으로 누르고 '모두 압축 풀기'를 선택하세요.
   ZIP을 더블클릭해서 들어간 상태에서는 실행하지 마세요.

2. 압축이 풀린 폴더를 열고 '모아 시작.bat'을 더블클릭하세요.
   확장자가 안 보이면 '모아 시작'으로 보일 수 있습니다.
   파일 종류가 'Windows 배치 파일'인 것을 여세요.

3. 처음에는 필요한 구성요소를 내려받아 준비하므로 몇 분이 걸릴 수 있습니다.
   인터넷에 연결하고 검은 창을 닫지 마세요.
   준비가 끝나면 브라우저에 모아가 자동으로 열립니다.

4. 모아 화면에서 '데이터 가져오기' → 엑셀 파일 선택 → 내용 확인 후 가져오기를 누르세요.
   제공하신 투자관리 엑셀을 선택하면 됩니다.
   다운로드 파일에는 개인 자산 데이터가 포함되지 않으므로 최초 한 번 필요합니다.

다음부터는 같은 '모아 시작.bat'만 더블클릭하면 됩니다.
종료할 때는 브라우저와 모아의 검은 실행 창을 닫으세요.

알아두세요
- Windows 10/11 64비트용입니다. Python과 Node.js를 직접 설치할 필요가 없습니다.
- 먼저 준비된 화면을 포함하므로 Node.js 설치나 빌드 명령어 입력이 필요 없습니다.
- 필요한 경우 Python은 python.org에서 내려받고 체크섬과 서명을 확인한 뒤 사용자 계정에 설치합니다.
- 스크린샷은 이 PC의 브라우저에서 인식합니다. 별도 OCR 프로그램 설치가 필요 없습니다.
- 자산 기록은 이 PC의 사용자 데이터 폴더에 저장됩니다. 앱에서 '데이터 백업'을 주기적으로 내려받으세요.
- 새 버전을 다른 폴더에 받아도 같은 Windows 계정으로 실행하면 기록이 유지됩니다.
- 인터넷에 공개하는 웹사이트는 아닙니다. 이 PC에서만 사용합니다.
- 오류가 나면 검은 창을 닫지 말고 마지막 오류 문구를 알려주세요.
  상세 기록은 Windows 키+R을 누르고 아래를 붙여넣으면 볼 수 있습니다.
